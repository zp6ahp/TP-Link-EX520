# Восстановление стокового ubi0

Файл `ubi0.bin` — дамп стокового раздела `ubi0` (40 МиБ) с TP-Link EX520 v1.
Он нужен только если установка OpenWrt прошла неудачно и роутер не загружается.

Калибровка Wi-Fi (`misc_ro`) и загрузчик (`boot`) в этом файле не затрагиваются.

## Как восстановить

1. Загрузите initramfs по TFTP (см. `../INSTALL.md`, раздел 3).
2. Положите `ubi0.bin` в папку TFTP-сервера рядом с `ex520.itb`.
3. В U-Boot:

```text
tftpboot 0x46000000 ubi0.bin
nmbm0 write 0x46000000 0xF00000 0x2800000
```

4. Выключите и включите питание.

Стоковый `ubi0` одинаков для всех EX520 v1 — калибровка хранится отдельно,
в `misc_ro`.
